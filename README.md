# Laurence Macaspac — Portfolio

Static HTML/CSS/JS portfolio. All seven real project screenshots are in `assets/` and are displayed in full without cropping.

## Upload to GitHub

Replace the existing repository files with `index.html`, `styles.css`, `script.js`, and the entire `assets/` directory. Vercel will automatically redeploy if connected.

## Hero photo

The original Unsplash workspace photo is retained, and the CSS confines it to the right portion of the hero at desktop widths. The left copy remains separate and readable at any width. The photo is remotely loaded from Unsplash, as in the previous version.
